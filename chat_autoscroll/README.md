# dsh-chat-autoscroll —— 聊天自动跟随（智能吸底）

**DSH 对话页在流式输出（思考 / 结果）时智能吸附到底部**：你停在聊天底部附近，就自动跟着
最新内容往下滚；你往上翻看历史时**不打断**，读回底部后自动恢复跟随。

纯浏览器半边插件，不改任何后端。

## 功能

- **智能吸底**：聊天滚动区在底部附近（距底部 80px 以内）时，每次流式追加内容都自动吸附
  到底，像主流聊天软件那样不用手拖。
- **不打扰阅读**：一旦你往上翻，立即停止跟随；滚回底部附近再继续跟随。
- **自动识别聊天滚动区**：不依赖前端给聊天列表预留的类名（那些类名都是 hash 过的、不稳
  定）。插件在运行时探测「可滚动 + 内容在增长」的容器，凡是 `scrollHeight > clientHeight`
  且 `overflowY` 可滚动（`auto / scroll / overlay`）的元素都进候选集，流式追加时只吸
  「当前停在底部」的那一个，天然只跟随聊天主滚动区、不影响侧边栏等其它可滚动面板。
- **会话切换自动适应**：周期重扫（每 3 秒）发现新挂载的聊天容器；切换会话后新滚动区也能
  被跟到。内容追加先去抖（150ms）再吸底，避免抖动。

## 使用

装上重启服务即可，**无需任何配置**。入口/开关：无独立界面；行为是即时的——你在底部就看
到消息自动滚，往上翻就停。

## 工作原理（要点）

- 用 `MutationObserver` / 定时重扫维护「可滚动容器」候选集；
- 对每个候选，跟踪其 `scrollTop + clientHeight` 是否接近 `scrollHeight`（距底 `STICK_GAP`
  内）；
- 流式追加去抖（`NUDGE_MS`）后，把「在底部」的容器 `scrollTop` 拉到最新。

## 数据 / 依赖

- 不写任何数据文件（无持久化，纯浏览器里即时生效）。
- 纯浏览器半边：只用到标准 DOM / MutationObserver，不依赖 React 内部。

## 安装（标准 npm bundle）

dshmarket 形态的 dsh 插件包：

```bash
python3 ~/.dsh/skills/dsh-plugin-install/scripts/install_plugin.py ./chat_autoscroll
# 或：dsh plugin --profile web add <chat_autoscroll 目录>
```

装完**菜单 → 重启服务**生效。

## 已知边界

- 吸底用的是启发式（可滚动元素 + 内容增长），极端自定义布局下可能把非聊天滚动区一起跟；
  若你用的是强自定义主题/布局，可能关闭更省心。
- 只在「内容追加」时吸底；如果你手动把滚动区点到中间读文，它不会乱拉（仅当你在底部时才动）。
